THROUGH MY CYPRIOT TELESCOPE — STARTER WEBSITE

WHAT'S INCLUDED
- index.html: the responsive, dark astronomy portfolio website.
- images/: place your own image files here when you prepare your gallery.

IMPORTANT
The current gallery uses example image URLs to demonstrate the layout. They are not your own astrophotographs. Replace these with your own photos before treating the gallery as your portfolio.

FREE HOSTING OPTION: GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository named: british-eyes-through-cypriot-skies
3. Upload index.html (and any image files you add) using the GitHub website's Add file > Upload files option.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. GitHub will publish the site at a URL similar to:
   https://YOUR-USERNAME.github.io/british-eyes-through-cypriot-skies/
   It can take a few minutes to appear.

PHOTO UPDATES WITHOUT CODE
This first version is a design prototype. Adding images to a folder alone will not make them automatically appear in the gallery. To keep photo management genuinely simple without editing code, the next step is to connect a no-code content editor/CMS. That setup needs your hosting/repository account and a few initial configuration steps. Alternatively, the site can be updated through GitHub's browser interface, but gallery cards/captions need configuration.

COST
GitHub Pages can host a public static website at no charge. A custom domain (for example, .com) is optional and normally costs money. Third-party image services and features may have their own limits/terms.

LOCAL PREVIEW
Open index.html in a web browser to preview the website. An internet connection is needed for the external sample images.
